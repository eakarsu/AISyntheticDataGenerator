# Quarantined Generated Surfaces

The original application contains generated routes, mock/sample data, direct chat completions, startup DDL, default credentials, silent integration errors, and gap modules. The frontend still includes prototype pages for some of them. They are not supported product behavior.

The former `gapNoNotificationsIntegrationsAuditLogSubsystemsOnlyStub.js` is superseded by durable integrations, notification outbox outcomes, signed webhook receipts, provider failures, usage, and append-only audit endpoints under `/api/governed-synthesis`. Reintroducing any quarantined route requires typed authoritative providers, tenant state, privacy evidence, explicit failure semantics, and acceptance tests equivalent to the governed API.
